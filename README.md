# ECE 362 Game Controller

## Project Discription
An RP2350-based handheld gaming console featuring a TFT LCD for display, MPU for motion control, microSD for game storage, PWM audio, dual joysticks, buttons, and d-pad for inputs.

## Project Objectives

### 1. Game Display (SPI)

### 2. Game Storage (SPI)

### 3. Motion Control (I2C)

### 4. Audio and Haptic Feedback (PWM)
