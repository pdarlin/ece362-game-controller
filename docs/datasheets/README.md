### 4. Built-in microSD Card Reader (TFT Module)
- [TFT Module SPI/microSD Wiring Guide](https://shillehtek.com/blogs/shillehtek-product-manuals/2-8-spi-tft-lcd-touch-screen-module-240x320-ili9341-for-arduino-manual)

The TFT includes a microSD socket that communicates over SPI.
No separate microSD reader module is required.

Connections:
- SD_CS: GP17
- SD_MISO: GP16
- SD_SCK: GP18
- SD_MOSI: GP19
